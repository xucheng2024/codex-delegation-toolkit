# Percent bands

Not official provider thresholds. Use only after the qualitative compact decision in `SKILL.md`. Token percent never overrides a veto.

- Below 35%: usually skip.
- 35 to 55%: compact only at a clear task boundary.
- 55 to 70%: if the current phase ended, strongly prefer compact after the checkpoint.
- Above 70%: seek the nearest safe checkpoint; do not hard-compact an unsolved problem.
- Above 80%: finish the smallest closed loop, then checkpoint and compact.
